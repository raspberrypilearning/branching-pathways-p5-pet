## 6A - Draw a place to live

Make somewhere your pet belongs. The starter pet can stay still while you work on its home.

> [!CAUTION]
>
> Have you [run your starter](1A%20-%20Meet%20your%20pet.md)? That is the only step you need first.

## Try the code

Replace **draw_home()**. Draw faraway things first and nearby things afterwards.

```python
def draw_home():
    background('skyblue')
    fill('gold')
    circle(330, 65, 65)
    fill('white')
    ellipse(95, 70, 100, 35)
    fill('lightgreen')
    rect(0, 290, 400, 110)
    fill('seagreen')
    triangle(15, 290, 65, 180, 115, 290)
```

## Test

Run your code. Your pet should appear in front of the scenery. Check its message is still easy to read.
