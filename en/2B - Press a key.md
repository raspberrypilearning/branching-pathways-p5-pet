## 2B - Press a key

Your pet can react to a key as well as a click.

> [!CAUTION]
>
> Have you [run your starter](1A%20-%20Meet%20your%20pet.md)? That is the only step you need first.

## Try the code

Replace **key_pressed()**. This first version accepts any key.

```python
def key_pressed():
    react()
```

## Test

Run your code. Click the visual output to focus it, then press a letter key. Your pet should react each time you press a key.
