## What comes first?

Run and test the starter before trying any other page. Every later option works with that starter on its own.

The sidebar offers a helpful order, not a required sequence. Controls, body, movement, personality and home can be changed independently. Options replacing the same function are alternatives. Keep one version, then edit it to combine ideas.

The site records the learner's confirmation; it does not inspect code in the editor. Warning boxes use the red/pink palette and link back to setup.
