# Sources

Reviewed 26 October 2026.

- [Python Bytes collection](https://github.com/raspberrypilearning/python-bytes/blob/master/en/step_1.md): links the food and animal projects that inspired this pathway.
- [Dot the Bug](https://github.com/raspberrypilearning/python-wild-dot-the-bug): building characters from layered p5 shapes.
- [Wiggle the Snake](https://github.com/raspberrypilearning/python-wild-wiggle-the-snake): moving connected body parts using shared coordinates and repeated movement.
- [Hop the Frog](https://github.com/raspberrypilearning/python-wild-hop-the-frog): click events, state and animated reactions.
- [Disgusting Dishes](https://github.com/raspberrypilearning/python-bytes-disgusting-dishes), [Gross Groceries](https://github.com/raspberrypilearning/python-bytes-gross-groceries) and [Recipe Wreckers](https://github.com/raspberrypilearning/python-bytes-recipe-wreckers): learner-authored language and playful personality.
- [Supported Code Editor libraries](https://help.editor.raspberrypi.org/hc/en-us/articles/30841379339924-Which-Python-libraries-are-available-in-the-Code-Editor): Python p5 support. This project targets that browser environment.
- [Pico Alarm pathway](https://github.com/raspberrypilearning/branching-pathway-alarm) and [Pico Musical Instrument pathway](https://github.com/raspberrypilearning/branching-pathways-pico-instrument): layout, colour palette, navigation and Markdown organisation. The web renderer and stylesheet are adapted from Alarm.

The pet starter, option snippets, lesson copy and vector illustrations were newly authored for this project. No learner choice requires a physical Pico or JavaScript/p5.js coding.
